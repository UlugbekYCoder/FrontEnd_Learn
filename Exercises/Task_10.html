Short explanations for DOCTYPE and HTML tags

Including:
• DOCTYPE
• HTML
• Head
• Body
• Element
• Attribute
• Heading
• Paragraph
• Comment
• Inline Style

Let's go

DOCTYPE → defines type of document and every html file is started with it

HTML → defines Hyper-Text Markup Language

Head And Body → Used to divide the code to two sections
Head - contains the most important thigs that are title, meta tags and connection of CSS and so on.
Body - contains all rest of code

Element → defines combination of opening tag(<p>) and content(Hello world!) and closing tag(</p>)

Attribute → thing inside opening tag, example: href: <a href=link><a>

Heading → defines heading of webpage

Paragraph → defines lines with <p> tag

Comment → used to make a code more readable and it doesn't appear on a webpage with >!-- --<
